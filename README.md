## 👋 About

Welcome to my personal developer portfolio.

This portfolio showcases my work as a **Frontend Developer** focused on crafting modern, immersive, and high-performance web experiences. Built with **React**, **Three.js**, **React Three Fiber**, **GSAP**, and **Tailwind CSS**, it combines interactive 3D graphics with smooth animations and a clean, responsive interface.
